# Valeria ❤️ — contador

Página web para mostrar dos contadores de tiempo:
- Desde el 21 de mayo de 2026
- Desde el 26 de junio de 2026

Ambos están configurados inicialmente a las 00:00 (hora peninsular española, +02:00).
Si conoces las horas exactas, edita `events` al final de `index.html`.

## Publicarla
Sube estos tres archivos a un alojamiento web estático (por ejemplo GitHub Pages, Netlify o Vercel). 
Después abre la URL en Safari en el iPhone y usa Compartir → Añadir a pantalla de inicio.

No necesita servidor ni base de datos.
